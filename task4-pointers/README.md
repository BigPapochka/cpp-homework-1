Задача 4 - кинотеатр

Программа бронирует места в нескольких залах. В каждом зале одинаковое число рядов и мест в ряду. Изначально все места свободны

Ввод

Сначала задаются размеры:

hallCount rowCount seatCount

Все размеры положительные, в ряду не больше 26 мест

Дальше вводятся заявки:


format hall row count


- format = 1 - места вводятся числами
- format = 2 - места вводятся заглавными буквами
- hall, row - выбранный зал и ряд
- count - число мест в заявке (должно быть положительным)

После заголовка нужно ввести count номеров или букв. Нумерация залов, рядов и числовых мест начинается с нуля. Буква A соответствует месту 0, B — месту 1 и так далее.

Чтобы закончить, вместо следующей заявки вводится один 0.

Вывод

Для каждого места программа печатает:

- booked - место забронировано;
- occupied - оно уже занято;
- error - такого места нет.

Места обрабатываются отдельно: ошибка одного не отменяет успешные брони остальных. При неправильном заголовке заявки программа печатает error и заканчивает чтение заявок. Если не удалось прочитать весь список мест, эта заявка не бронируется.

В конце выводится состояние всех залов: 0 - свободно, 1 - занято.

Пример.

Ввод:

1 1 5
2 0 0 2
A C
0

Создаётся один зал с одним рядом из пяти мест. В нём бронируются первое и третье места.

Вывод:

booked
booked
Hall 0
Row 0: 1 0 1 0 0

Указатели

int*** seats хранит динамические массивы: залы, ряды и состояния мест. Обращение к одному месту имеет вид seats[hall][row][seat].

void* chosenSeats хранит адрес списка выбранных мест. Формат определяется при вводе, поэтому список создаётся как int[] или char[]. Перед чтением, обработкой и удалением указатель приводится к соответствующему типу.

После каждой заявки её буфер освобождается. В конце удаляются массивы мест, затем массивы указателей на ряды и общий массив залов. Вся программа находится в main, стандартные контейнеры не использую
